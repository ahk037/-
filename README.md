# ETEVERS EOCR Partner Day

2026년 12월 9일 파트너 행사 안내 및 신청 체험 페이지입니다.

## 사이트 수정

- 사이트 파일: 저장소 루트의 `index.html`
- 배포 브랜치: `main`
- Vercel 프로젝트: `eocr-partner-day` (etevers 팀)
- 사이트 주소: https://eocr-partner-day.vercel.app

`index.html`을 수정해 `main`에 커밋하거나 푸시하면 Vercel Git 연동으로 자동 배포됩니다. 로컬 파일 저장만으로는 배포되지 않습니다.

외부 라이브러리 설치나 빌드 명령 없이 HTML을 그대로 제공합니다.

## 신청 폼
